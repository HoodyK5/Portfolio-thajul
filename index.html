    Cybersecurity Intern

    ShadowFox

    • 1 month
    • Practical lab assessment

    A month of hands-on security work in authorised lab environments. Each task is handed in as a written report with the objective, tools, methodology, evidence, findings, risk assessment, remediation and conclusion.

    Beginner

    3 tasks
    • Open port identificationFind the open ports and services on an authorised test web server and explain what they expose.
    • Web directory enumerationDiscover public directories and resources, record HTTP response codes and assess the risk.
    • Authentication traffic analysisCapture login traffic in Wireshark and show whether credentials travel in plaintext or encrypted.

    Intermediate

    4 tasks
    • VeraCrypt container analysisWork out whether a supplied value is an encoding or a password hash, recover the password and open the encrypted container.
    • PE entry-point analysisRead the headers of a Windows executable in PE Explorer and record its Address of Entry Point.
    • Metasploit reverse-shell labRun a controlled payload and reverse shell between isolated lab machines while monitoring the network and the endpoint.
    • Wi-Fi security assessmentReview a network I own, study handshakes and password strength, and recommend fixes.

    Advanced

    1 of 3 options
    • Full penetration testOne structured penetration test, chosen from TryHackMe King of the Hill (Panda), TryHackMe Basic Pentesting, or a web application assessment of a test site.
    • Professional reportScope, methodology, evidence, risk ratings, privilege-escalation analysis where relevant, and a remediation plan.
